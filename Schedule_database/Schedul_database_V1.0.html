0 oder leer verwendet den Ringdurchmesser. Umrechnung in Inch mit 25,4 mm/Inch und sechs Nachkommastellen.

Ein importierter Programmordner wird als eine Auswahl gespeichert. Beim Abrufen werden alle darin enthaltenen XML-Dateien angepasst und zusammen als ZIP heruntergeladen. Einzelne hochgeladene XML-Dateien werden ebenfalls als ZIP mit einer Datei bereitgestellt. Die gespeicherten Originale bleiben unverändert.
