Liburdi Schedule Editor v2.9 - Help

Start

Open this HTML file in a current browser. For the full feature set (segment field order, XDR schemas from the Schedule Database) serve the project folder with python3 -m http.server 8000.

Loading XML files

  1. Click Open XML… or drop XML files on Drop XML files here.
  2. Only valid schedules (<sched> with at least one segment) are accepted.
  3. Click a file in the list to make it the active file.
  4. Use the checkboxes (or Select all / Clear / Invert) for batch actions.

Files are processed in the browser only. Files on disk stay unchanged until you save.

Editing

The sections Description, Global, Limits, Overrides and Segments can be edited directly. Decimal comma and point are both accepted. Changed values are highlighted; hover a value to see the last saved value.

If the active file is selected, edits outside of Segments are also applied to all other selected files.

Hover a parameter row to mark it as important (★) or hide it (⊘). Double-click and right-click on the name do the same.

Drag a parameter row by its name or handle (⠿) to reorder it; Alt+↑/↓ on the handle moves it by one row. The order is stored per section (all segments share one order) and included in the Local Storage Backup. Reset order in the panel header restores the default order. Locked parameters (🔒) cannot be moved and keep their position.

In Segments, segments can be duplicated, moved and deleted. The selected segment stays open.

Keyboard shortcuts

  • Ctrl+S save, Ctrl+Shift+S save as
  • Ctrl+Z undo, Ctrl+Y / Ctrl+Shift+Z redo (inside an input field the browser's own undo applies)
  • Ctrl+F or / search, Esc clear search or close dialog

Saving

  • Save: download the active file with its current name.
  • Save As…: download the active file under a new name; the file is renamed.
  • Batch Save: save the selected files (all files if none are selected). An optional revision tag (e.g. Rev1) is appended to every file name (Name_Rev1.xml); an existing _Rev… suffix is replaced and the files are renamed in the editor. Several files are saved as a ZIP archive.
  • Revert: reset all loaded files to the last saved state.

Tools

  • Comparison: compare loaded files, edit values, transfer values to all files, optionally show differences only.
  • Heat Input: heat input per segment with efficiency η = 0.6 (background values during excursion, primary values during indwell/outdwell); min/max from the percentage overrides. A chart shows the min–max range and nominal value per segment, with the heat input limits from <limits> as dashed lines. Enter a target Min/Max to draw red reference lines.
  • Hidden Parameters: restore hidden parameters.
  • Change Log: show recorded changes.
  • XML Viewer: read-only XML of the active file; with a saved XDR schema, missing required values are marked in red.
  • Local Storage Backup: export or import the editor settings as JSON.

Local settings

Hidden and important parameters, custom heads, units, the change log and the sidebar state are stored in the browser's localStorage.

Local Storage Backup

Export or import the local editor settings as a JSON file. Importing replaces the stored editor settings and reloads the page.
