How to Use the Simplified Editor

This is the simplified version of the layout editor. Only the three most-used pages (JOG, WELD, WELD2) are editable. The generated XML still includes all nine modes — the other six are written with factory defaults, or with the values from a loaded file if one is provided.

  1. Loading: Click "Choose File" to load an existing key_layout_*.xml file. All nine modes are read in, but only JOG, WELD, and WELD2 are exposed for editing.
  2. Editing:
    • Switch between JOG, WELD, and WELD2 using the orange tabs.
    • Change any button's function using its dropdown.
    • For custom functions, select "--- CUSTOM ---" and type a value.
  3. Copy / Paste: Use "Copy page" to capture the current mode, then switch to another mode tab and use "Paste page" to overwrite it. The clipboard indicator shows which mode is currently held.
  4. Blank page: Use "Fill page with blank_black" to wipe the current mode and start from scratch. A confirmation prompt appears first.
  5. Preview as PDF: Click "Preview Layout as PDF" to open a printable view of the three editable pages with their button icons. Use the print dialog's "Save as PDF" option to keep a copy.
  6. Saving: Enter an author and file suffix, then click "Generate & Download XML". The output contains all nine modes.
